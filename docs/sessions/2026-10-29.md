### 15:13 -- Fix AI Assistant trên production: OpenAI calls qua site HTTP proxy

**Triệu chứng:** AI Assistant trên prod "chưa thấy chạy được" — drawer không sinh token nào.
Dev VPS (`100.102.133.86`) thì chạy bình thường.

**Root cause (không phải bug logic):**
- Prod VPS **không có direct internet egress** — mọi outbound connection phải đi qua site HTTP proxy
  `192.168.154.101:1985` (khai trong `/etc/environment` + `/etc/profile.d/proxy.sh` trên host prod).
  `curl --noproxy '*' https://api.openai.com` → timeout 10s.
- **Node's built-in `fetch` (undici) KHÔNG đọc `HTTPS_PROXY`** theo mặc định. OpenAI SDK dùng
  `fetch` → timeout tới Cloudflare IP (`UND_ERR_CONNECT_TIMEOUT`, `APIConnectionTimeoutError`).
  → Backend log prod: `[assistant] error: APIConnectionTimeoutError: Request timed out.`
- Node >= 24 có `NODE_USE_ENV_PROXY=1` làm proxy toàn cục, nhưng image prod chạy **Node 22** → không dùng được.

**Fix (qua git → GitHub CI, không edit trực tiếp trên VPS):**
- `backend/src/services/assistant/llmClient.ts`
  - Thêm `undici` dep (`^7.30.1`).
  - `resolveProxyUrl()`: ưu tiên `OPENAI_PROXY_URL`, fallback `HTTPS_PROXY`/`HTTP_PROXY` (cả lowercase).
    Validate URL, ignore giá trị rỗng/rác.
  - Khi có proxy → dựng `new ProxyAgent(proxyUrl)` và gắn vào OpenAI client qua
    `fetch: undiciFetch` + `fetchOptions: { dispatcher }`. Không có proxy → giữ đường direct.
  - Align default model: `gpt-4.1-mini` → **`gpt-4o-mini`** (code default trước đây lệch với
    compose; `gpt-4.1-mini` route tool kém với 55+ tools).
- `backend/src/routes/assistant.ts`
  - `describeAssistantError()`: dịch lỗi undici thô thành message hành động được
    (timeout → "set OPENAI_PROXY_URL", 401 → sai key, ENOTFOUND → DNS, 429 → quota).
  - Endpoint mới `GET /api/assistant/status` — probe không gọi LLM, báo
    `hasApiKey` / `proxyConfigured` / `model` / `tools`.
- `docker-compose.app.yml`: `OPENAI_PROXY_URL: ${OPENAI_PROXY_URL-}` (default rỗng → host
  không có proxy vẫn đi direct; dùng `-` không phải `:-` để empty trong .env vẫn empty).
- `.github/workflows/deploy-prod.yml`
  - Ghi `OPENAI_PROXY_URL=http://192.168.154.101:1985` vào prod `.env` (override được bằng env).
  - Step mới **"Verify AI assistant can reach OpenAI"**: chạy 1 streaming completion thật qua
    đúng code path của assistant, fail deploy nếu OpenAI không reachable.
