### 07:55 -- NetBox READ tools cho AI assistant (Phase 2)

User yêu cầu: "làm tiếp cho netbox, coi lại doc netbox và llm, xem hướng làm
để query netbox, thực hiện các thao tác liên quan đến netbox từ ai assistant".

**Ngữ cảnh & quyết định**:
- Đã có: worker `netboxClient` (1600+ dòng) + 2 task `NETBOX_SYNC_DEVICE/_ALL` + scheduler 5 phút
- Đã có: 2 assistant tools `sync_to_netbox` / `sync_all_to_netbox` (WRITE only)
- THIẾU: assistant KHÔNG thể QUERY NetBox — user muốn "trong NetBox có bao nhiêu
  switch site NKKN", "F2-AS-01 trong NetBox có bao nhiêu port", "sync lần cuối
  khi nào, cái nào fail"
- Phạm vi (Q&A 4 câu):
  1. **Phase 1 READ** (query) — không làm reverse sync / write-on-NetBox
  2. **Backend HTTP route** (in-process) — không qua worker job
  3. **Tất cả tool con** (devices, sites, roles, manufacturers, IPAM, interfaces, sync_status)
  4. (skip)

**Approach chốt**: backend client tương tự `keaDhcp.ts` (Node `fetch` với
`Token {NETBOX_TOKEN}` auth). NetBox client ở worker vẫn là chỗ mutate; backend
client chỉ GET. Tách 2 file tránh duplicate code (HTTP fetch helper 1 nơi).
