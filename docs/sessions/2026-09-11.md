**Backend** (1 service + 1 route + 1 mount):

- `backend/src/services/search.ts` — `searchAll(q, { limitPerGroup })`
  chạy 7 sources song song qua `Promise.allSettled`:
  1. `Device` — name/ip/serial/vendor/model/version/description
     (Prisma `mode: 'insensitive'`)
  2. `ArpAddress` — fetch `getArpInventory()` rồi filter client-side
     (ARP rows sống trong `Job.result`, không có bảng riêng)
  3. `MacAddress` — `getMacAddressInventory()` filter tương tự
  4. `DeviceLog` — `listLogs({ q, limit, hideNoise: false })`
  5. `Job` — match error text + device name + device ip
     (Job.type là enum nên `contains` không có ý nghĩa; bỏ)
  6. `AuditLog` — path/method/userId; route tự filter ADMIN-only
  7. `DHCP` — `keaCommand('query4', { query: 'subnet4-get-all' })` rồi
     gọi `lease4-get-all` cho mỗi subnet song song, match IP/MAC/hostname
- MAC normalization: `matches(haystack, q)` strip tất cả separator
  khỏi cả 2 phía để `aa:bb:cc` và `aabbcc` đều khớp. Nếu query có ≥6
  hex chars thì match cả khi user quên dấu `:`.
- `backend/src/routes/search.ts` — `GET /api/search?q=...&limit=3`.
  - Min query 2 chars → 400 nếu ngắn hơn (chống spam)
  - Audit strip ở route layer cho non-admin
  - `strictRateLimit` chung với các GET khác
- `backend/src/index.ts` — mount `/api/search` với `authMiddleware +
  strictRateLimit`. Đặt cạnh `/api/audit-log` (route cùng pattern).

**Trade-off / notes**:
- DHCP source gọi N `lease4-get-all` (1 cho mỗi subnet) song song; nếu
  có 5 subnet thì = 5 RPC đến Kea. Có thể cache lease inventory ở
  scheduler cycle như `getArpInventory` đã làm (Phase 2 nếu lab chậm).
- `searchArp` / `searchMac` đọc toàn bộ inventory rồi filter client-side
  vì data thật nằm trong `Job.result` JSON. Nếu fleet >50 thiết bị
  thì parse toàn bộ sẽ chậm — Phase 2 có thể query `Job.result` JSON
  trực tiếp bằng `prisma.$queryRaw` (Postgres có `jsonb` ops).
- `Job.type` không filter được vì là enum. Nếu user muốn search theo
  job type literal (vd "INTERFACE_ACTION") thì phải đổi schema sang
  String — không làm.
- Audit group chỉ cho ADMIN. Operator/VIEWER sẽ không thấy group Audit
  ngay cả khi có match.
- Frontend chưa làm match-highlight trong row text (Phase 2 polish).
