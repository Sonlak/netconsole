# 2026-09-14

## 14:00 -- Fix deploy + rollback failures

### Root causes fixed

1. **Deploy fail: container name conflict**
   - Lệnh `docker compose up --build --force-recreate` bị abort khi frontend container bị conflict
   - `set -euo pipefail` abort toàn step → backend/frontend bị bỏ ở trạng thái "Created" (chưa chạy)
   - nginx không tìm thấy upstream `backend` → restart loop
   - **Fix:** tách thành `stop` → `rm -sf` → `up -d --build --no-deps`
   - Commit: `6bb6260`

2. **Auto-rollback fail: marker không tồn tại**
   - Marker chỉ được lưu ở CUỐI deploy thành công
   - Nếu deploy fail trước step đó → marker không có → rollback fail
   - Deploy fail liên tiếp → marker bị ghi đè bằng commit lỗi → rollback trỏ vào commit lỗi
   - **Fix:** backup marker TRƯỚC deploy vào `.rollback-before-deploy-sha`
   - Auto-rollback đọc backup này (priority 1) trước, fallback sang `.last-deploy-sha` (priority 2)
   - Commit: `5b3d1c2`

3. **Frontend health check trong auto-rollback dùng HTTPS sai**
   - Site hiện tại chạy HTTP trên 8443 (đổi từ HTTPS ngày 2026-09-08)
   - Health check trong rollback dùng `https://127.0.0.1:8443` → luôn fail
   - **Fix:** đổi sang `http://127.0.0.1:8443`
   - Commit: `5b3d1c2`

### Deploy flow recap

```
git push origin main
  → GitHub Actions: Deploy (self-hosted on vps-prod-01)
    1. Save rollback marker (backup current → .rollback-before-deploy-sha)
    2. Sync source to /opt/netconsole
    3. docker compose stop + rm -sf + up -d --build --no-deps
    4. Health checks
    5. Save deploy marker (SUCCESS path: update .last-deploy-sha)
  → If deploy fail: Auto-rollback job runs
    → reads .rollback-before-deploy-sha
    → checkouts prev commit → rsync → rebuild → health check
```
