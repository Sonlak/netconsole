### Critical fixes applied (code)
- **`backend/src/middleware/auth.ts`** — fail-fast trên missing JWT_SECRET (was: fallback `'CHANGE_ME_IN_PRODUCTION'`); thêm `iss`/`aud` claims; cookie helpers; password-redaction helper.
- **`backend/src/websocket/terminal.ts`** — shared `verifyToken` (was: local copy + `'netconsole-dev-secret'` fallback); WS upgrade đọc `nc_refresh` HttpOnly cookie (was: `?token=` URL); output redacted trước khi persist (PCI-DSS 3.2).
- **`backend/src/index.ts`** — `app.set('trust proxy', 1)`; `helmet()` với CSP + HSTS + X-Frame-Options + Permissions-Policy; body parser 25 MB → **1 MB**; `cookieParser` cho refresh-cookie flow.
- **`backend/src/routes/auth.ts`** — bcrypt 12 → **13 rounds**; `nc_refresh` HttpOnly+Strict cookie set on login + refresh, cleared on logout; DB-backed loginAttempt lockout sau 5 fail/15min; AuditLog row ghi khi `replay_detected`.
- **`backend/src/middleware/loginAttempt.ts` (NEW)** — per-(username, ip) lockout, persists qua backend restart.
- **`backend/src/services/syslogReceiver.ts`** — source-IP CIDR allowlist (`SYSLOG_ALLOWED_CIDRS`); per-IP token bucket (50 pps burst 200); drop counter log mỗi phút.
- **`backend/prisma/schema.prisma`** — `LoginAttempt` model; `TerminalSession.metadata` JSON cho redacted capture.
